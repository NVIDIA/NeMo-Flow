Use this page to plan an upgrade to NeMo Relay 0.9.

## Upgrade to NeMo Relay 0.9

Plugin-host APIs changed in NeMo Relay 0.9. Earlier global initialization,
validation, report, clear, and dynamic activation-spec APIs are removed.

Use [Configure and Initialize Plugins](/configure-plugins/initialize-plugins)
to migrate to `initialize`, `validate`, and exact validation. Keep the returned
activation handle for the full plugin lifetime and close it during shutdown.
